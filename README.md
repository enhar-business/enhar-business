# ANHAR Business
منصة أعمال ومحاسبة سحابية متعددة الشركات والفروع.

## الحالة
هذه إعادة تأسيس للواجهة والبنية الأمامية. الواجهة الحالية تعرض بيانات توضيحية فقط، ولم يتم بعد ربط المصادقة أو Supabase أو تنفيذ القيود المالية الفعلية.

## التشغيل
افتح `index.html` أو انشر المستودع عبر GitHub Pages.

## بنية المشروع
- `index.html`: نقطة دخول التطبيق.
- `assets/css/app.css`: نظام التصميم المتجاوب.
- `assets/js/app.js`: التنقل ومكونات الواجهة.
- `docs/ARCHITECTURE.md`: حدود النظام وخطة التنفيذ.
- `supabase/migrations/`: ترحيلات قاعدة البيانات المعتمدة لاحقاً.

## قواعد أساسية
- واجهة عربية RTL، داكنة، كحلي وذهبي.
- عزل بيانات الشركات عبر company_id وسياسات RLS.
- مركز اشتراكات ANHAR خاص بمدير المنصة فقط.
- لا تُعتمد أي عملية مالية قبل ربطها بقيود مزدوجة واختبارها.
- لا تضع مفاتيح Supabase السرية أو service_role في الواجهة أو GitHub.
